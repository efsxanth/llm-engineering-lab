# Customer Feedback Analyser

A Python application that uses a cloud-hosted large language model
(LLM) to transform unstructured customer reviews into validated,
structured data.

Built with LangChain, GroqCloud and Pydantic.

## Features

- Classifies customer sentiment as positive, neutral or negative.
- Identifies whether a product was purchased as a gift.
- Extracts delivery times mentioned in customer reviews.
- Summarises customer opinions about pricing.
- Validates generated output against a Pydantic schema.
- Uses LangChain Expression Language (LCEL) to connect the prompt,
  language model and output parser.
- Supports automated testing without real API calls through dependency
  injection and fake language models.

## Requirements

- Python 3.12 or newer.
- A GroqCloud account and API key.
- An internet connection to access the hosted LLM.

## Installation

Clone the repository and navigate to its root directory.

Create a Python virtual environment:

```powershell
python -m venv .venv
```

Activate the virtual environment on Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

Install the Customer Feedback Analyser and its development dependencies:

```powershell
python -m pip install -e ".\projects\01_customer_feedback_analyser[dev]"
```

## Configuration

Copy `.env.example` from the repository root to a new file named `.env`.

Add your GroqCloud API key and configure the model:

```dotenv
GROQ_API_KEY=your_api_key_here
GROQ_MODEL=openai/gpt-oss-20b
GROQ_TEMPERATURE=0
```

The `.env` file contains private credentials and must not be committed
to GitHub. It is excluded by `.gitignore`.

## Usage

From the repository root, run the example application:

```powershell
python .\projects\01_customer_feedback_analyser\examples\analyse_review.py
```

The application analyses a sample customer review and displays the
structured result as JSON.

Example output:

```json
{
  "sentiment": "positive",
  "is_gift": true,
  "delivery_days": 3,
  "price_assessment": "Considered a bit expensive."
}
```

The exact wording may vary because the response is generated by an LLM.

## Testing

The project includes automated tests for:

- Pydantic schema validation.
- Valid and invalid LLM responses using a fake chat model.
- Empty and whitespace-only customer reviews.
- Inputs with incorrect data types.

The tests use `pytest` and do not require real Groq API calls.

Run all tests from the repository root:

```powershell
python -m pytest .\projects\01_customer_feedback_analyser\tests -v
```

```text

├── pyproject.toml

│       └── schemas.py
```

- `analyser.py` — Coordinates input validation, the LLM and output parsing.
- `prompts.py` — Defines the reusable LangChain prompt template.
- `schemas.py` — Defines the Pydantic output schema.
- `examples/` — Contains a runnable example using the real Groq API.
- `tests/` — Contains automated tests for validation and analyser behaviour.
- `pyproject.toml` — Defines package metadata, dependencies and tool configuration.
